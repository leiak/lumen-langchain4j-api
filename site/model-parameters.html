模型参数

根据你选择的模型和提供者，你可以调整众多参数，这些参数将定义以下内容：

  • 模型的输出：生成内容（文本、图像）中的创造性或确定性程度，生成内容的体积等。
  • 连接性：基础 URL、授权密钥、超时、重试、日志等。

通常，你可以在模型提供者的网站上找到所有参数及其含义。 例如，OpenAI API 的参数可在 https://platform.openai.com/docs/api-reference/chat （最新版本）找到，包括以下选项：

| 参数 | 描述 | 类型 | | modelName | 要使用的模型名称（例如，gpt-4o、gpt-4o-mini 等） | String | | temperature | 要使用的采样温度，介于 0 和 2 之间。较高的值（如 0.8）将使输出更随机，而较低的值（如 0.2）将使输出更加聚焦和确定。 | Double | | maxTokens | 在聊天补全中可以生成的最大令牌数。 | Integer | | frequencyPenalty | 介于 -2.0 和 2.0 之间的数值。正值会根据新令牌在文本中的现有频率对其进行惩罚，从而降低模型逐字重复相同句子的可能性。 | Double | | ... | ... | ... |

有关 OpenAI 大语言模型中参数的完整列表，请参阅 OpenAI Language Model 页面。 每个模型的完整参数列表和默认值可在单独的模型页面中找到（在 Integration、Language Model 和 Image Model 下）。

你可以通过两种方式创建 *Model：

  • 静态工厂：仅接受必需参数（如 API 密钥），所有其他必需参数设置为合理的默认值。
  • 构建器模式：在此处，你可以为每个参数指定值。

模型构建器

我们可以使用构建器模式设置模型的每个可用参数，如下所示：

OpenAiChatModel model = OpenAiChatModel.builder() .apiKey(System.getenv("OPENAI_API_KEY")) .modelName("gpt-4o-mini") .temperature(0.3) .timeout(ofSeconds(60)) .logRequests(true) .logResponses(true) .build();

在 Quarkus 中设置参数

Quarkus 应用程序中的 LangChain4j 参数可以在 application.properties 文件中设置，如下所示：

quarkus.langchain4j.openai.api-key=${OPENAI_API_KEY}quarkus.langchain4j.openai.chat-model.temperature=0.5quarkus.langchain4j.openai.timeout=60s

有趣的是，对于调试、微调甚至只是了解所有可用参数，可以在 Quarkus DEV UI 中查看。 在此仪表板中，你可以进行更改，更改会立即反映到正在运行的实例中，并且你的更改会自动同步到代码中。 可以通过使用命令 quarkus dev 运行 Quarkus 应用程序来访问 DEV UI， 然后你可以在 localhost:8080/q/dev-ui 上找到它（或在你的应用程序部署的任何位置）。

有关 Quarkus 集成的更多信息，请点击此处。

在 Spring Boot 中设置参数

如果你使用的是我们的 Spring Boot 启动器之一， 你可以在 application.properties 文件中配置模型参数，如下所示：

langchain4j.open-ai.chat-model.api-key=${OPENAI_API_KEY}langchain4j.open-ai.chat-model.model-name=gpt-5.4-mini...
