Payara Micro 集成

LangChain4j 可以无缝集成到 Payara Micro 应用中，借助 Jakarta EE 和 MicroProfile 的标准特性来实现依赖注入与配置管理。

本指南演示如何创建 JAX-RS 资源，这些资源直接实例化并使用 LangChain4j 模型，配置由 MicroProfile Config 进行管理。

Maven 依赖

首先，在你的 pom.xml 文件中添加 langchain4j 核心依赖以及你需要的特定模型集成模块：

<properties> <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding> <maven.compiler.release>21</maven.compiler.release> <jakartaee-api.version>10.0.0</jakartaee-api.version> <payara.version>6.2025.5</payara.version> <version.langchain4j>1.22.0</version.langchain4j></properties><dependencies> <dependency> <groupId>dev.langchain4j</groupId> <artifactId>langchain4j-open-ai</artifactId> <version>${version.langchain4j}</version> </dependency> <dependency> <groupId>dev.langchain4j</groupId> <artifactId>langchain4j-google-ai-gemini</artifactId> <version>${version.langchain4j}</version> </dependency> <dependency> <groupId>jakarta.platform</groupId> <artifactId>jakarta.jakartaee-api</artifactId> <version>${jakartaee-api.version}</version> <scope>provided</scope> </dependency></dependencies>

配置多个模型

你可以通过在 MicroProfile 配置文件中（位于 src/main/resources/META-INF/microprofile-config.properties）提供各自的属性来配置多个 AI 模型，如下所示：

openai.api.key=${OPENAI_API_KEY}openai.chat.model=gpt-4o-minigoogle-ai-gemini.chat-model.api-key=${GEMINI_KEY}google-ai-gemini.chat-model.model-name=gemini-2.0-flash-litedeepseek.api.key=${DEEPSEEK_API_KEY}deepseek.chat.model=deepseek-reasoner

实现聊天资源

在此方式中，每个 JAX-RS 资源负责管理自己的 AI 模型实例。该模式会在每个服务提供商中重复使用。

RestConfiguration 类继承 jakarta.ws.rs.core.Application，并为所有 REST 端点定义基础路径 /api：

import jakarta.ws.rs.ApplicationPath;import jakarta.ws.rs.core.Application;@ApplicationPath("api")public class RestConfiguration extends Application {}

对于每个模型，我们都有一个 JAX-RS 资源类，它会完成以下操作：

  • 使用 @Inject 和 @ConfigProperty 注入配置属性。
  • 使用带有 @PostConstruct 注解的方法，在属性注入完成后再构建模型实例。
  • 创建一个 @GET 端点以与模型交互。
@Path("openai")public class OpenAiChatModelResource { @Inject @ConfigProperty(name = "openai.api.key") private String openAiApiKey; @Inject @ConfigProperty(name = "openai.chat.model") private String modelName; private OpenAiChatModel chatModel; @PostConstruct public void init() { chatModel = OpenAiChatModel.builder() .apiKey(openAiApiKey) .modelName(modelName) .build(); } @GET @Path("chat") @Produces(MediaType.TEXT_PLAIN) public String chat(@QueryParam("message") @DefaultValue("Hello") String message) { return chatModel.generate(message); }}

同样的模式也用于 GeminiChatModelResource 和 DeepSeekChatModelResource。

注意，最后一个资源复用了 OpenAiChatModel 类，只是将 baseUrl 改为了 deepseek 的 API，这展现了本库的灵活性。

运行示例应用

该项目配置为使用 Payara Micro Maven 插件运行。

前置条件：

  • Java SE 21 及以上
  • 已安装 Maven

执行步骤

  • 在项目的根目录打开一个终端。
  • 设置 API 密钥所需的环境变量。应用需要这些变量来对 AI 服务进行身份验证。你必须配置以下变量：

OPENAI_API_KEY GEMINI_KEY DEEPSEEK_API_KEY

  • 执行以下 Maven 命令：mvn clean package payara-micro:start

服务器启动后，你可以通过以下两种方式测试端点：

  • 如果你使用的是 IntelliJ IDEA（Ultimate 版）或其他具有类似功能的 IDE，可以直接在 .http 文件中执行请求： a. 打开 src/test/resources/ 下的 test.http 文件。 b. IDE 会在每个请求定义旁边显示一个小的绿色“播放”图标： c. 点击要运行的请求旁边的图标。API 的响应将直接显示在 IDE 的工具窗口中：
  • 使用 AI 聊天界面 在浏览器中导航至 http://localhost:8080/。这将打开一个交互式聊天页面，你可以直接在浏览器中浏览和测试可用的端点：
