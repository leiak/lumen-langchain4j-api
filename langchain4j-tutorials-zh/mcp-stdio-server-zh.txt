LangChain4j 提供了一个 MCP 客户端（langchain4j-mcp）用于连接 MCP 服务器。
如果你想构建一个基于 Java 的 MCP stdio 服务器（由 MCP 客户端启动的本地子进程），
请使用社区模块：langchain4j-community-mcp-server。

本指南展示了通过 stdio 暴露现有 @Tool 注解方法的最小设置（基于 JSON-RPC）。
如果你的服务器应该作为可通过网络访问的独立服务运行，请参见 Streamable HTTP 服务器。

## 添加依赖

添加 BOM（推荐）：

```
<dependencyManagement> <dependencies> <dependency> <groupId>dev.langchain4j</groupId> <artifactId>langchain4j-bom</artifactId> <version>${latest version here}</version> <type>pom</type> <scope>import</scope> </dependency> <dependency> <groupId>dev.langchain4j</groupId> <artifactId>langchain4j-community-bom</artifactId> <version>${latest version here}</version> <type>pom</type> <scope>import</scope> </dependency> </dependencies></dependencyManagement>
```

然后添加社区 MCP 服务器依赖：

```
<dependency> <groupId>dev.langchain4j</groupId> <artifactId>langchain4j-community-mcp-server</artifactId></dependency>
```

## 实现工具

使用 @Tool 暴露你的功能：

```
import dev.langchain4j.agent.tool.P;import dev.langchain4j.agent.tool.Tool;class Calculator { @Tool long add(@P("a") long a, @P("b") long b) { return a + b; }}
```

MCP 工具参数名称取自 Java 方法参数名称。
请使用 -parameters javac 选项编译你的项目，
否则 MCP 客户端将看到诸如 arg0 和 arg1 之类的通用名称：

```
<build> <plugins> <plugin> <groupId>org.apache.maven.plugins</groupId> <artifactId>maven-compiler-plugin</artifactId> <configuration> <parameters>true</parameters> </configuration> </plugin> </plugins></build>
```

## 启动 stdio 服务器

```
import dev.langchain4j.community.mcp.server.McpServer;import dev.langchain4j.community.mcp.server.transport.StdioMcpServerTransport;import dev.langchain4j.mcp.protocol.McpImplementation;import java.util.List;public class McpServerMain { public static void main(String[] args) throws Exception { McpImplementation serverInfo = new McpImplementation(); serverInfo.setName("my-java-mcp-server"); serverInfo.setVersion("1.0.0"); McpServer server = new McpServer(List.of(new Calculator()), serverInfo); new StdioMcpServerTransport(System.in, System.out, server); // 在 stdio 打开期间保持进程存活 Thread.currentThread().join(); }}
```

cautionStdioMcpServerTransport 将 JSON-RPC 协议写入 System.out。
请确保你的日志配置为写入 System.err（否则你将破坏协议流并导致客户端断开连接）。

## 打包为可运行的 JAR

MCP 客户端（例如 Claude Desktop）通常期望启动一个本地服务器进程。
将你的服务器打包为可运行的（fat）JAR 是一种常见方法，但任何可运行的进程都可以。

## 配置 MCP 客户端

### .mcp.json

许多 MCP 客户端从 .mcp.json 文件中读取服务器定义：

```
{ "mcpServers": { "my-java-tool": { "type": "stdio", "command": "java", "args": ["-jar", "/absolute/path/to/my-java-mcp-server.jar"] } }}
```

### Claude Desktop

在 claude_desktop_config.json 中添加一个服务器条目：

```
{ "mcpServers": { "my-java-tool": { "command": "java", "args": ["-jar", "/absolute/path/to/my-java-mcp-server.jar"] } }}
```

请使用绝对路径；在 Windows 上，需要对反斜杠进行转义。

## Streamable HTTP 服务器

stdio 传输为每个进程服务单个本地客户端。
如果你的 MCP 服务器应该作为可由多个（本地或远程）客户端共享的独立服务运行，
请使用 Streamable HTTP 传输。
langchain4j-community-mcp-server 不提供此传输，但以下 Java 库提供（按字母顺序列出）：

| 库 | 描述 |
| Helidon MCP | Helidon 应用程序的 MCP 服务器支持 |
| MCP Java SDK | Model Context Protocol 的官方 Java SDK，独立于任何框架 |
| Micronaut MCP | Micronaut 应用程序的 MCP 服务器支持 |
| Quarkus MCP Server | Quarkus 应用程序的 MCP 服务器支持 |
| Tachyon | Java 和 Kotlin 的 MCP 服务器库 |

这些是独立的项目，不由 LangChain4j 团队维护。
请参阅它们各自的文档以了解设置、安全性（身份验证、TLS）和部署。

服务器运行后，将 MCP 客户端指向其端点 URL，例如在 .mcp.json 中：

```
{ "mcpServers": { "my-java-tool": { "type": "http", "url": "http://localhost:8080/mcp" } }}
```

Claude Desktop 仅启动本地进程，
因此请使用 mcp-remote 将其连接到 Streamable HTTP 服务器：

```
{ "mcpServers": { "my-java-tool": { "command": "npx", "args": ["-y", "mcp-remote", "http://localhost:8080/mcp"] } }}
