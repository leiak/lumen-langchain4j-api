一些 LangChain4j 模块（目前是 OpenAI 和 Ollama）支持自定义用于调用 LLM 提供商 API 的 HTTP 客户端。

langchain4j-http-client 模块实现了一个 HttpClient SPI，该 SPI 被这些模块用来调用 LLM 提供商的 REST API。
这意味着底层 HTTP 客户端可以被自定义，并且任何其他 HTTP 客户端都可以通过实现 HttpClient SPI 来集成。

目前有以下开箱即用的实现：

- 来自 langchain4j-http-client-jdk 模块的 JdkHttpClient。
当使用支持的模块（例如 langchain4j-open-ai）时，它默认被使用。
- 来自 langchain4j-http-client-spring-boot4-restclient/langchain4j-http-client-spring-restclient 模块的 SpringRestClient。
当使用受支持模块的 Spring Boot 启动器（例如 langchain4j-open-ai-spring-boot4-starter/langchain4j-open-ai-spring-boot-starter）时，它默认被使用。
- 来自 langchain4j-http-client-apache 模块的 ApacheHttpClient。
- 来自 langchain4j-http-client-okhttp 模块的 OkHttpClient。

## 自定义 JDK 的 HttpClient

```
HttpClient.Builder httpClientBuilder = HttpClient.newBuilder() .sslContext(...);JdkHttpClientBuilder jdkHttpClientBuilder = JdkHttpClient.builder() .httpClientBuilder(httpClientBuilder);OpenAiChatModel model = OpenAiChatModel.builder() .httpClientBuilder(jdkHttpClientBuilder) .apiKey(System.getenv("OPENAI_API_KEY")) .modelName("gpt-4o-mini") .build();
```

noteHttpClient 实现还可以提供非阻塞的对应版本：executeAsync(...) 用于单个响应，stream(...) 用于已解析服务器发送事件的冷 Flow.Publisher。捆绑的 JDK、OkHttp 和 Apache 客户端都实现了这两个方法，SpringRestClient 在 classpath 上有 spring-webflux 时也是如此。
请参阅非阻塞和响应式。

## 自定义 Spring 的 RestClient

```
RestClient.Builder restClientBuilder = RestClient.builder() .requestFactory(new HttpComponentsClientHttpRequestFactory());SpringRestClientBuilder springRestClientBuilder = SpringRestClient.builder() .restClientBuilder(restClientBuilder) .streamingRequestExecutor(new VirtualThreadTaskExecutor());OpenAiChatModel model = OpenAiChatModel.builder() .httpClientBuilder(springRestClientBuilder) .apiKey(System.getenv("OPENAI_API_KEY")) .modelName("gpt-4o-mini") .build();
```

SpringRestClient 使用 RestClient 发送阻塞请求，使用 WebClient 发送非阻塞请求（executeAsync(...) 和 stream(...)），后者需要在 classpath 上有 spring-webflux。由于 spring-webflux 是可选的，因此 WebClient.Builder 通过 WebClientBuilderHolder 传入：

```
SpringRestClientBuilder springRestClientBuilder = SpringRestClient.builder() .restClientBuilder(RestClient.builder()) .webClientBuilder(WebClientBuilderHolder.of(WebClient.builder())) .clientHttpConnectorBuilder(ClientHttpConnectorBuilder.reactor()); // 可选：固定连接器
```

## 自定义 Apache 的 HttpClient

```
org.apache.hc.client5.http.impl.classic.HttpClientBuilder httpClientBuilder = org.apache.hc.client5.http.impl.classic.HttpClientBuilder.create();ApacheHttpClientBuilder apacheHttpClientBuilder = ApacheHttpClient.builder() .httpClientBuilder(httpClientBuilder);OpenAiChatModel model = OpenAiChatModel.builder() .httpClientBuilder(apacheHttpClientBuilder) .apiKey(System.getenv("OPENAI_API_KEY")) .modelName("gpt-4o-mini") .build();
```
