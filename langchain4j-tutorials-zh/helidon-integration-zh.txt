Helidon 提供了一个 LangChain4j 集成模块，可在使用 Helidon 编程模型与风格的同时，
简化 AI 驱动应用的构建。

你可以在此处找到 LangChain4j 集成功能的详细说明与使用方法。

## 支持的版本

Helidon 的 LangChain4j 集成需要 Java 21 与 Helidon 4.2。

## 示例

我们创建了若干示例应用供你探索。这些示例演示了在 Helidon 应用中使用 LangChain4j 的各个方面。

### 咖啡店助手

咖啡店助手（Coffee Shop Assistant）是一个演示应用，展示了如何为一家咖啡店构建一个由 AI 驱动的助手。
该助手可以回答关于菜单的问题、提供推荐以及创建订单。它使用了一个由 JSON 文件初始化的向量存储。

主要特性：

- 与 OpenAI 聊天模型的集成
- 利用嵌入模型、向量存储、数据导入器（ingestor）以及内容检索器
- 使用 Helidon Inject 进行依赖注入
- 从 JSON 文件初始化向量存储
- 支持通过回调函数增强交互

参考示例：

- Helidon SE 版咖啡店助手
- Helidon MP 版咖啡店助手
